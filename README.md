# Sales Analytics Dashboard (Excel)

An interactive Excel dashboard that analyzes sales performance across regions, product categories and time (2010–2017).

## Overview
Built during my Data Analytics training at IBA Karachi. The dashboard turns raw sales records into KPIs and charts that can be filtered with slicers.

## Dataset
- Source: [state it honestly, e.g. "sample dataset provided during training"]
- Records: 100 orders
- Fields: Region, Country, Item Type, Sales Channel, Order Priority, Order Date, Units Sold, Unit Price, Unit Cost, Revenue, COGS, Profit

## KPIs
- Total Revenue: $137.35M
- Total Profit: $44.17M
- Profit Margin: 32.16%
- Total COGS: $93.18M
- Total Orders: 100
- Units Sold: 512,871

## Visuals
- Revenue by Region (bar chart)
- Online vs Offline sales (pie chart)
- Revenue by Order Priority (stacked column chart)
- Revenue trend by Year (line chart)
- Profit vs COGS by Item Type (line chart)

## Interactivity
Slicers for Region, Item Type and Order Date update every chart and KPI at once.
